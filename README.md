# 软件工程每日任务台 · SE Daily Hub

一个**单文件、纯前端、双击即用**的软件工程学习打卡应用。为「大三 → 暑期实习 → 秋招」这条路线设计，
把每天该做的事、该跟的竞赛、该练的英语、该读的开源项目，全都收进一个页面里。

> 🌐 **在线预览：[https://vivian0113com.github.io/daily_mission/](https://vivian0113com.github.io/daily_mission/)**
> （或直接下载 `index.html`，双击用浏览器打开 —— 无需安装、无需后端、断网也能用）

---

## 这是什么

大三最怕的不是不努力，是**不知道今天该干什么**，以及**努力了但没有反馈**。

这个页面把这两件事解决了：每天早上打开它，任务已经按你的年级和难度派好了；
做完打卡，进度、连续天数、分类投入占比、周复盘会自动算出来。

**所有数据只存在你自己的浏览器里**（`localStorage`，前缀 `sehub_`），不上传任何服务器。
换电脑时导出/导入即可迁移。

## 英语板块详解

技术英语不是「背单词」，是**在真实场景里能读懂、能写出来、能讲清楚**。所以这里做了六块：

- **📖 阅读** —— 20 篇技术主题短文，配生词高亮与中文译文。支持**关键词搜索**（标题 / 标签 / 生词 / 正文 / 译文加权匹配），
  搜不到就去 **GitHub 抓一篇真实的英文技术文档**回来读。
- **🎧 听力** —— 三遍精听法（盲听 → 对照 → 复述）+ 6 个可用资源。
- **🎤 口语** —— 跟读打分（浏览器语音识别）+ **纯本地录音回放**的备用模式。
  国内 Chrome 的识别服务连不上 Google 服务器，页面会检测并引导换 Edge，或直接用录音对比法。
- **🗂️ 词汇** —— 每天 6 个技术高频词 + 快速自测。
- **📝 翻译练习** —— **24 道技术场景题**（面试 / 项目描述 / 技术文档 / 邮件沟通 / 日常交流），
  中英双向。写完提交，会算出你**关键表达命中率**、给出参考译文和得分要点。
  例：`我叫李明，是软件工程专业的大三学生，主要做后端开发。`
  → 会自动检查你有没有用上 `junior`、`majoring in`、`Software Engineering`、`backend development`，
  并解释**为什么**这么写（「大三说 junior 或 third-year student，别说 big three」）。
- **🔄 即时翻译** —— 中英互译，带最近 12 条历史；右侧配**完全离线的本地技术词表**，断网也能查。
  **阅读时选中任意单词或句子，松手就弹出翻译**。

## 技术实现

**刻意保持单文件。** 全部 HTML / CSS / JS 内联在一个 `index.html` 里，没有构建步骤、没有依赖、没有 `node_modules`。

为什么？
- 双击就能用，不需要装环境、不需要起服务 —— 对「每天要打开」的工具来说，**打开成本多一步就等于不会用**
- 可以随手丢进 U 盘、发给自己、放网盘
- 十年后还能打开（不会被 npm 生态的考古问题搞死）

**一些实现细节：**

- **三套皮肤 × 明暗双主题**：Apple 极简 / Ins 渐变 / 经典靛蓝，用 `data-skin` × `data-theme` 两个正交属性驱动，
  变量层 + 覆盖层双层结构（新增皮肤只要加一组变量覆盖，不用重写组件）
- **外部服务全部做了降级路径**：
  | 服务 | 用途 | 挂了怎么办 |
  |---|---|---|
  | GitHub REST API | 推荐开源项目 / 抓取英文文档 | 降级为内置精选清单 |
  | MyMemory 翻译接口 | 即时翻译 / 划词翻译 | 提示联网 + 引导用离线词表 |
  | Web Speech API | 口语跟读打分 | 引导换 Edge，或用纯本地录音回放 |
- **MyMemory 接口的两个坑**（踩过）：返回文本是 HTML 实体编码需要解码；
  配额用尽时它会把警告文案塞进 `translatedText`，**不能当译文展示**，要识别 `quotaFinished` 和 `MYMEMORY WARNING`
- **零依赖测试**：用 jsdom 无头加载页面，模拟点击、断言 DOM，覆盖 **635 条**用例（含可控 `fetch` 打桩验证联网成功 / 断网 / 接口限流三条路径）

## 数据说明

- 所有数据存在浏览器 `localStorage`，键名前缀 `sehub_`
- **不会上传任何数据**，页面没有任何埋点
- 清除浏览器数据会一起清掉，重要记录建议定期在「学习档案」里导出
- 竞赛时间依据往年公开信息整理，**请以各赛事官方最新通知为准**
